Система автоматического анализа и категорирования событий информационной безопасности

Моя программа реализует онтологический подход к анализу событий информационной безопасности с построением графа

Что реализовано:

1. Автоматическое категорирование событий ИБ
2. Программа распознает русский и английский язык текста сообщения об угрозе
3. Строит RDF-онтологию
4. Строит граф знаний в общем формате и в индивидуальном формате
5. 
Чтобы запустить:

1. Открыть папку проекта
2. Открыть терминал и указать путь к папке проекта
3. Создать виртуальное окружения "py -m venv venv"
4. Активировать виртуальное окружение ".\venv\Scripts\Activate.ps1"
5. Установить библиотеки pip install pathlib matplotlib networkx rdflib
6. Запустить файл main.py "py main.py"
7. 
После запуска:

1. Создается папка report, где создаются файлы report/png1.png..png21.png
Это файлы где изображены графы по каждой аттаке
2. Создается файл infosec_graph.png, где изображены все графы на одной картинке.
3. Создается файл онтологии в формате RDF infosec_ontology.rdf
